OPEN-CORE // APACHE 2.0

An open 3D creation station, right in the browser.

Code sovereignty

Universal access

No downloads. If there is a modern browser, there is Expctral.

Native performance

WebGPU gives direct access to modern graphics cards, with parallel compute shaders.

ECOSYSTEM // 4 SURFACES

      
Four surfaces, one ecosystem.

      
Integrated gears designed to shorten the distance between creative intent and scalable monetization.

    

    

      

        ENGINE // SINAPSE
        
Sinapse Engine

        
The WebGPU core with a visual TSL compiler. Dual pipelines: Compute Pass for physics and particles, Render Pass for geometry, light and materials.

      

      

        STUDIO // PRISM
        
Prism Studio

        
Node-based authoring for TSL shaders and materials, with real-time multiplayer collaboration (Yjs CRDTs) and synthetic audio.

      

      

        REGISTRY // ORBIT CLUSTER
        
Spectral Registry

        
Community gallery and marketplace: test every item live in the browser, refract projects with automatic credit and sell with an 85/15 split.

      

      

        HUB // LANDING
        
Landing Hub

        
The site itself as a living showcase of the technology. The site proves the product.

Frequently asked questions

    

      
What if I want to leave the platform?
Click [ ⚡︎ EJECT TYPESCRIPT ]. Your node graph becomes a clean .ts file with pure TSL functions that only needs standard Three.js. It runs on any server or React/Next.js app, with no Expctral dependencies.

      
Can I use it in a commercial product?
Yes. Apache 2.0 allows unrestricted commercial use without opening your product's code, grants an explicit patent license from every contributor and only asks you to keep the copyright notices in modified original files.

      
What if my browser doesn't support WebGPU?
Expctral falls back to WebGL2 automatically. TSL transpiles to both WebGPU and WebGL, so the code you write today is future-proof.

      
Where does my support go?
Through the Open Source Collective. The first goal (R$ 15,000) covers servers, domains, certificates and the initial Sinapse Compiler infrastructure. The second (R$ 50,000) consolidates Prism Studio, brings in senior engineering support and prepares the angel round.

      
Can companies sponsor with tax benefits?
Expctral is fiscally hosted by the Open Source Collective, a US 501(c)(6) nonprofit ready to receive B2B sponsorships from American and European companies with tax deduction. Sponsors get their brand in the Hub footer and a direct engineering channel.

      
How does the marketplace work?
In the Spectral Registry, creators publish TSL materials, presets and 3D projects. 85% of each sale goes to the creator (via Stripe Connect or Open Source Collective) and 15% stays with the platform for infrastructure and engine development.
