    ARCHITECTURE // SINAPSE + PRISM
    Built on open standards, end to end.
    
      
    Four decisions that turn a visual graph into fast, portable code.
    
    
    
    
    
      
    
        
    
          
    01 // DUAL PIPELINES
    
          
    Compute and render in parallel
    
          
    The Compute Pass runs physics, particles and instancing on storage buffers inside the GPU. The Render Pass receives that data already in memory and draws geometry, light and TSL materials.
    
        
    
        
    
          
    
            COMPUTE PASS · WORKGROUP 64
            ↓
            STORAGE BUFFER · STD430 · 16 B
            ↓
            RENDER PASS · TSL MATERIAL
          
    
        
    
      
    
      
    
        
    
          
    02 // VISUAL TSL COMPILER
    
          
    Nodes become native TSL functions
    
          
    Instead of concatenating fragile GLSL or WGSL strings, every node maps to a real TSL function. Shaders created visually are syntactically valid and transpile to both WebGPU and WebGL.
    
        
    
        
    

    // Spectrum Color node → TSL
material.colorNode = mix(
  uSpectrumA, uSpectrumB,
  clamp(uMix.add(hash(instanceIndex)), 0, 1)
);
    
        
    
      
    
      
    
        
    
          
    03 // 0% LOCK-IN
    
          
    Eject clean TypeScript at any time
    
          
    The graph is transpiled into a standalone .ts file with pure TSL functions. It only needs standard Three.js and runs on any server or React/Next.js app.
    
          
        
    
        
    

    import * as THREE from 'three/webgpu';
import { Fn, uniform, instancedArray } from 'three/tsl';
// zero proprietary dependencies
export function createVortex(renderer) { … }

    Frequently asked questions
    
    
    
      
    What if I want to leave the platform?
    Click [ ⚡︎ EJECT TYPESCRIPT ]. Your node graph becomes a clean .ts file with pure TSL functions that only needs standard Three.js. It runs on any server or React/Next.js app, with no Expctral dependencies.
    
      
    Can I use it in a commercial product?
    Yes. Apache 2.0 allows unrestricted commercial use without opening your product's code, grants an explicit patent license from every contributor and only asks you to keep the copyright notices in modified original files.
    
      
    What if my browser doesn't support WebGPU?
    Expctral falls back to WebGL2 automatically. TSL transpiles to both WebGPU and WebGL, so the code you write today is future-proof. The live counter at the top of this page shows which renderer your browser is using right now.
    
      
    Where will my support go?
    The first goal (R$ 15,000) covers servers, domains, certificates and the initial Sinapse Compiler infrastructure. The second (R$ 50,000) consolidates Prism Studio, brings in senior engineering support and prepares the angel round.
    
      
    How does OSC governance work?
    The plan is fiscal hosting through the Open Source Collective, a US 501(c)(6) nonprofit, with GitHub Sponsors integration for community and B2B sponsorship and public financial transparency. Enrollment is still in progress.
    
      
    How does the marketplace work?
    In the Spectral Registry, creators publish TSL materials, presets and 3D projects. 85% of each sale goes to the creator and 15% stays with the platform for infrastructure and engine development.
    
      
    Can I use the platform already?
    Development follows phases 0 to 4 (see the roadmap above). Today you can try the Prism Studio prototype on this page and eject its TypeScript.
