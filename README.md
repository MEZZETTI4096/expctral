# Expctral — Landing Hub

Landing page da **Expctral**, ecossistema open-core de criação 3D no navegador (WebGPU + TSL, Apache 2.0), de Gabriel Mezzetti — Mezzetti⁴⁰⁹⁶ Studio.

- Página no ar: https://mezzetti4096.github.io/expctral/
- Idiomas: inglês, português e chinês (`?lang=en`, `?lang=pt`, `?lang=zh`)
- Inclui um protótipo interativo do Prism Studio (editor de nós, 4 frequências, Refract e Eject TypeScript)

Arquivo único (`index.html`), sem build. Para trocar o destino dos botões, edite `CTA_LINK` no início do script.
Itens marcados `[PREENCHER: …]` ainda aguardam informação real.
